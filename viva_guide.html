1. Project Core Concepts (Elevator Pitch)

System Purpose

Automates a single-runway airport traffic controller where arriving and departing aircraft share a unified queue. Emergency flights instantly preempt routine traffic.

Data Structure Choice

Custom Singly Linked List Priority Queue implemented from scratch without java.util. Enqueue and Dequeue operate in constant O(1) time.

Operation Queue Action Time Complexity Aviation Rule
Routine Flight Inserted at Tail (rear) O(1) Standard FIFO (First-In, First-Out) order
Emergency Flight Inserted at Head (front) O(1) Safety Priority (Bypasses routine line)
Runway Dispatch Removed from Head (front) O(1) Clears highest-priority waiting flight

👤 Elna Elizabeth Abraham Node.java   FlightQueue.java
Data Structures & Core Algorithms
Core Responsibility: Built a custom Singly Linked-List Priority Queue with front and rear pointers from scratch. Zero reliance on java.util collections.
Q1: Why did you implement a Linked List instead of an Array for the Queue?
Dynamic memory allocation (no static size boundary) and O(1) insertion/deletion without needing to shift elements like an array.
Q2: How does your Priority Queue logic work without loops?
If an incoming flight is routine, rear.next = newNode; rear = newNode; (tail insertion). If it's an emergency, newNode.next = front; front = newNode; (head insertion). Both execute in O(1) time.
30-Second Viva Speech: "I engineered our custom Priority Queue using a Singly Linked List with front and rear pointers. Routine flights join at the tail in FIFO order, while emergency flights jump directly to the head. All queue operations execute in O(1) time."

2. Individual Member Modules (Part 2)

👤 K Sruthika RunwayUI.java
UI & System Integration
Core Responsibility: Designed the classic Swing GUI with JFrame, setBounds (null layout), and implements ActionListener to connect the visual interface to the underlying data structure.
Q1: How does the UI connect with the Queue data structure?
When the user clicks 'Add Flight', it triggers runwayQueue.enqueue(flight). When 'Clear Runway' is clicked, it calls runwayQueue.dequeue() and refreshes the display text areas.
Q2: Why use a single unified queue on the interface?
Because in a single-runway airport, all arriving and departing aircraft compete for the same physical runway. Having one list makes priority preemption immediately visible to air traffic controllers.
30-Second Viva Speech: "I built the graphical interface using pure Java Swing with null layout and setBounds, matching our lab coursework. My module captures user input, updates the queue visually, and dispatches flights via button events."
👤 Devika Suresh FileHandler.java   TestRunway.java
File Handling & Testing
Core Responsibility: Manages persistent logging to runway_log.txt using FileWriter in append mode and created automated headless test verification scripts.
Q1: Why did you use append mode (new FileWriter(FILE_NAME, true))?
Passing true prevents overwriting past flight history, ensuring an audit log of all runway clearances is permanently preserved on disk.
Q2: What edge cases did you verify with TestRunway.java?
1. Queue underflow (attempting to clear an empty runway shows an alert without crashing). 2. Verifying that emergency flights inserted after routine flights dequeue first.
30-Second Viva Speech: "I implemented persistent audit logging using FileWriter in append mode and built TestRunway.java to programmatically verify our priority queue logic and underflow protection without needing the GUI."
